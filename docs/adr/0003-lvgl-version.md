# ADR-0003：LVGL 版本

- 状态：已采纳
- 日期：2026-09-26

## 决策

使用 **LVGL v9.5.0**，固件和 PC 模拟器使用同一个版本，并且锁定版本号。

## 理由

- v9 是当前主线，v8 只剩维护。新项目直接用 v9，文档和示例也以 v9 为准。
- **不用 v9.6.0**：它 2026-09-16 才发布，只有 10 天；v9.5.0 已发布 7 个月，周边组件
  （esp_lvgl_port 等）的适配更稳。
- 固件和模拟器用同一个 LVGL 版本和同一套 `lv_conf` 关键配置（RGB565、字体），
  模拟器截图才能代表真机效果。

## 待定（M1 决定）

- 屏幕驱动组件的选型（esp_lcd + ST7735 驱动的具体来源）、是否使用 `esp_lvgl_port`。
  M1 开始前补一份 ADR。
