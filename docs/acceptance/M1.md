# M1 验收清单：屏幕、LVGL、摇杆

负责：开发者。标 **[自动]** 的项由 Claude 通过串口或 CI 检查，其余由开发者目测或操作确认。

## 显示

- [ ] 屏幕显示的画面和模拟器截图 `demo.png` 一致：文字、布局、背景色都相同
- [ ] **1 像素白框四边完整可见**，没有被裁掉，也没有多出一条花边（验证显示偏移 `set_gap`）
- [ ] 色条从左到右依次是 **红、绿、蓝、白**（验证 RGB/BGR 顺序和字节序）
- [ ] 背景是深蓝黑色，而不是浅色（验证是否需要反色）
- [ ] 画面没有闪烁、撕裂、随机噪点，连续运行 10 分钟不花屏
- [ ] 实测的偏移、反色、镜像参数写进 `docs/requirements.md` 的"已知硬件约束"

## 摇杆

- [ ] **[自动]** 五个键分别按下时，串口各打印一次对应方向（上 / 下 / 左 / 右 / 中）；按住不放不会连续刷屏
- [ ] **[自动]** 所有键松开时，串口没有任何按键事件（重点关注 **GPIO13**：它同时接着 LED D5，
      松开时读到的电平是否可靠？）
- [ ] **[自动]** 中键长按 3 秒，串口打印一次"长按"事件；短按不会触发长按
- [ ] 屏幕上显示最近一次按键事件（证明按键和 LVGL 已经连通，而且没有跨任务直接调用 LVGL）
- [ ] 实测的"方向 ↔ GPIO"对应关系写进 `docs/requirements.md`（以屏幕横放、文字正向为准）

## 启动可靠性

- [ ] 不按任何键，连续复位 10 次都能正常启动（L2 冒烟测试 PASS）
- [ ] 记录**按住哪个方向键上电会进入下载模式**（GPIO9 是 BOOT 脚），写进 `docs/requirements.md`

## 工程

- [ ] 用 PR 合并，CI 三个 job 全绿
- [ ] 模拟器和固件显示的是**同一份** UI 代码，不是各复制一份
- [ ] 至少一条踩坑日志
